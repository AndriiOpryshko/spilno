## Findings

1. **[stage-1] A large amount overflows int64 and a wrong equivalent is stored for good**
   - Where: `services/core/internal/finance/domain/rate.go:67-71`, `services/core/internal/finance/domain/contract.go:61`. AC-02, ADR-0002.
   - Problem: `Convert` returns `n.Int64()` without checking `IsInt64()`, and `amount_cents` has no maximum. At rate 50.5311, 2e17 cents gives −8340524073709551616 kopiyky, which is persisted and never recomputed.
   - **Verdict: fix now.** `Convert` returns `(UAHEquivalent, error)` when the result does not fit in int64:
     - Create stores the contract without an equivalent and logs it, as in AC-04;
     - resolve answers with a defined problem;
     - a boundary test row is added to `rate_test.go`.
2. **[stage-1] The live contract lacks the operation's `x-problem-types`, and the registry test reads only the delta**
   - Where: `services/core/api/openapi.yaml:102-130` vs `contracts/openapi.yaml:36-43`; `services/core/internal/finance/domain/errors_test.go:12`. AC-07.
   - **Verdict: fix now.**
     - Copy the `x-problem-types` block into the live operation.
     - Point `TestRegistryStatusesMatchContractProblemTypes` at `services/core/api/openapi.yaml`.
3. **[stage-2] The promoted migration still carries the staging header**
   - Where: `services/core/migrations/00050_add_contracts_uah_equivalent.sql:1-2`.
   - **Verdict: fix now.** Drop the "Staged as … / Promote with …" lines.
4. **[stage-2] The rate-source URL is logged in full at startup**
   - Where: `services/core/cmd/api/main.go:173`.
   - **Verdict: fix now.** Log only the redacted form (`url.Parse` → `Redacted()`, or scheme + host).
5. **[stage-2] The NBU client's safety limits are untested**
   - Where: `mcp/nbu-rates/internal/nbu/nbu.go:59`, `:98`.
   - **Verdict: fix now.** Add two cases to `TestRateErrors`:
     - a body over 1 MiB → `ErrUnavailable`;
     - a blocking upstream with a short ctx deadline → `ErrUnavailable`, returned promptly.
