## Findings

1. **[stage-1] SAD §8 Logging promises more redaction than the code gives since T29.**
   - Where: `sad.md:183-184`. AC: AC-10.
   - Problem: the SAD says the error never contains the endpoint's userinfo, query or fragment. The code behaves differently:
     - URL tokens are cut to scheme + host + path (`mcprates.go:193-196`).
     - Outside URLs, only secret parts of at least 6 bytes are masked (`minMaskedSecret`, `mcprates.go:27-29`, `:202-208`).
     - `unavailable_internal_test.go:150,159` asserts that `k=abc` stays in the error.
   - **Verdict: fix now** → T30.
2. **[stage-1] The epic's task-map prose still describes the T01–T12 plan.**
   - Where: `tasks/_epic.md:16`. AC: n/a.
   - Problem: it says "Longest chain: 7". In the T01–T29 DAG the longest chain is 12: T02 → T05 → T07 → T08 → T09 → T10 → T16 → T18 → T23 → T25 → T26 → T27. The day-one starts also leave out T17, which has no deps.
   - **Verdict: fix now** → T31.
3. **[stage-2] A `"` in `NBU_RATES_MCP_URL` still leaks secrets into the logged error.**
   - Where: `mcprates.go:32` (`urlToken` stops at `"`), `:188-190` (the endpoint's spellings are matched unescaped), `:104` (an unparsable endpoint gets no secrets). AC: AC-10.
   - Problem: net/http prints the URL with `%q`, so the error carries `\"`. That form matches no known spelling, and the token ends at the quote.
   - Reproduced through `Rate` against a closed port:
     - `?token="quoted-secret"` gives `Post "http://127.0.0.1:1/mcp"quoted-secret\""`.
     - `http://u:pa"ss-secret@127.0.0.1:1/mcp` gives `parse "<unparsable>"ss-secret@…`.
   - An operator must configure the quote, so this is unlikely, but it breaks "no secret in logs".
   - **Verdict: fix now**, by refusing such an address at start-up → T32.
4. **[stage-2] A secret of 6 bytes or more that is also part of the host still garbles the message.**
   - Where: `mcprates.go:121`, `:203-207`. AC: AC-10.
   - Problem: `http://127.0.0.1:1/mcp?h=127.0.0.1` gives `dial tcp ***:1: connect: connection refused`. The mask hides nothing, because `endpoint=` prints the host anyway.
   - **Verdict: fix now** → T33.
