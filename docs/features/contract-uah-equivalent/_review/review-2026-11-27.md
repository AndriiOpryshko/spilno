## Findings

1. **[stage-1] The SAD still says the adapter adds no timeout, but T25 gave it one**
   - Where: `sad.md:175` (§8 Timeouts), the mcprates row in §5; `tasks/T05-mcp-rate-provider.md:33`. AC-04, AC-10.
   - Problem: since 997898d the adapter bounds every HTTP request by the caller's deadline, with a 3 s `fallbackBudget` (`mcprates.go:26-28`, `:48-74`). It also refuses redirects (T23, `:54`). None of T23–T25 updated sad.md.
   - **Verdict: fix now** → T26.
2. **[stage-1] The epic's AC coverage table and DAG stop at T12**
   - Where: `tasks/_epic.md:59-71`. AC-02, AC-04, AC-07, AC-10.
   - Problem: tasks.json maps the follow-up tasks T13–T25 to these ACs, but `_epic.md` does not. So the out-of-range criterion added to AC-02/04/07 shows no implementing task in the epic.
   - **Verdict: fix now** → T27.
3. **[stage-2] The T25 regression test barely catches a removed fix** (both reviewers raised this on their own)
   - Where: `adapters/mcprates/mcprates_test.go:249-285`; the fix is at `mcprates.go:55` and `:131`. AC-04, AC-10.
   - Problem: the stub hangs on every request, including `initialize`. So `Connect` fails before `tools/call`, and the notifications/cancelled path is reached only by chance.
     - Against the pre-T25 `mcprates.go` the test passes 3/3.
     - With `deadlineTransport` replaced by `http.DefaultTransport` it fails only 6 of 40 runs.
     - The `fallbackBudget` (no deadline) path has no test. A probe gives 3.0 s with the fix and 13 s without.
     - A stub that completes initialize and hangs on `tools/call` catches the regression every time: without the fix, a `notifications/cancelled` request is still open 3 s later.
   - **Verdict: fix now** → T28.
4. **[stage-2] Masking secrets as substrings garbles the logged error and can corrupt its placeholder**
   - Where: `adapters/mcprates/mcprates.go:99`, `:105-109`, `:177`, `:182-184`. AC-10 (log line `app/contracts.go:91`).
   - Problem: every username, query value and fragment is replaced anywhere in the message, however short.
     - `?v=1` gives `dial tcp ***27.0.0.***:…`.
     - User `a` gives `c***lling "initi***lize"`.
     - `?x=end` corrupts the placeholder: `Post "\x00***point\x00"`, with NUL bytes in the log and no address.
     - Nothing leaks, and the default URL has no secrets.
   - **Verdict: fix now** → T29.
