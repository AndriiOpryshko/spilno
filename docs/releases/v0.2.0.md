# spilno 0.2.0: охайніші договори

Невеликий реліз, присвячений надійності: тепер договір не збережеш із контрагентом, який
лише здається заповненим.

## Що змінилося для вас

**Контрагент у договорі має бути справжнім.** Раніше spilno приймав контрагента, у назві
якого були лише пробіли або невидимі символи (табуляція, перенос рядка), і такий договір
зберігався без назви. Тепер spilno відмовляє зберегти такий договір і прямо вказує, що
саме з полем «Контрагент» щось не так. Якщо випадково поставити пробіл перед назвою чи після
неї, наприклад « ТОВ Ліфт-Сервіс », договір збережеться як і раніше.

## Для тих, хто розвиває spilno

Тепер на одному комп'ютері можна паралельно працювати над кількома завданнями. Кожна робоча
копія отримує власні порти, базу даних і залежності, тож дві версії застосунку не
заважатимуть одна одній.

Дякуємо, що користуєтесь spilno!
