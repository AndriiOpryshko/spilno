# spilno 0.3.0: договори в гривнях за курсом НБУ

Тепер для договорів у євро чи доларах spilno сам рахує суму в гривнях. Більше не треба шукати
курс і перемножувати вручну перед засіданням правління чи перевіркою ревізійної комісії.

## Що змінилося для вас

**Гривневий еквівалент договору.** Для договору в EUR або USD spilno бере офіційний курс
Національного банку на день підписання й рахує суму в гривнях. Поруч зберігаються курс, дата
курсу та джерело (НБУ), тож будь-хто може перевірити, звідки взялося число. Еквівалент
рахується один раз і потім не змінюється, навіть якщо пізніше хтось ще раз попросить його
порахувати.

**Договір не губиться, якщо НБУ мовчить.** Якщо в момент створення договору джерело курсу
недоступне, договір усе одно зберігається, просто поки без гривневої суми. Її можна отримати
пізніше однією дією. Якщо ж НБУ ще не опублікував курс на день підписання, spilno так і
скаже, а не підставить курс іншого дня.

Поки що еквівалент доступний через API spilno. Окремий екран для нього з'явиться в одному з
наступних релізів.

## Надійність і безпека

Ми посилили роботу з джерелом курсу: запит до нього не може тривати довше, ніж дозволено,
перенаправлення не виконуються, а службові адреси й ключі не потрапляють
ні в повідомлення про помилки, ні в журнали.

Дякуємо, що користуєтесь spilno!
